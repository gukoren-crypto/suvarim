# שוברים

[פתיחת האפליקציה](https://gukoren-crypto.github.io/suvarim/) · [מאגר הקוד](https://github.com/gukoren-crypto/suvarim)

האתר הציבורי נפתח עם ארנק ריק. אפשר לחבר מכשירים לארנק מוצפן בענן באמצעות מפתח פרטי, ללא מייל. לחלופין אפשר להעביר גיבוי באופן פרטי ולשחזר אותו בטלפון.

גרסה ראשונית של ארנק שוברים אישי בעברית, מותאמת לאנדרואיד ולמחשב. React + Vite, אחסון IndexedDB, OCR באמצעות Tesseract.js, מפת Leaflet/OpenStreetMap וניווט ב־Google Maps.

## הרצה

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

בדיקות דפדפן (כשהשרת המקומי פועל): `npm run test:browser`. בדיקת OCR אמיתית עם תמונה פיקטיבית: `npm run test:ocr`. בדיקת פתיחה ללא רשת מול `npm run preview`: `node scripts/verify-offline.mjs`. יש להתקין Chromium ל־Playwright או להגדיר `PLAYWRIGHT_CHROMIUM_EXECUTABLE` לנתיב דפדפן מקומי.

אומתו במהלך הפיתוח: 24 בדיקות לוגיקה; 7 תרחישי דפדפן, כולל שמירת יתרה בלי סכום מקורי, אישור קטלוג Swish והחלפה בין מסלולי DREAM CARD; בדיקת נגישות אוטומטית למסך הארנק; תצוגה ברוחב 390 ו־320 פיקסלים; OCR אמיתי של תמונת בדיקה; פתיחה ללא רשת של שובר שמור בגרסת ההפצה. בדיקת OCR זו אינה מדד לדיוק על תמונות שוברים אמיתיות בעברית. לא בוצעה עדיין בדיקה על מכשיר אנדרואיד פיזי.

להפצה: יש להעלות את תוכן `dist` לשרת סטטי ב־HTTPS. האפליקציה מניחה כתובת בסיס `/`. השרת צריך להגיש את `sw.js` ללא קאש ממושך. אין צורך בסודות או מפתחות API לגרסה זו. פתיחה בטלפון באותה רשת דרך כתובת ה־IP של המחשב מאפשרת לראות את הממשק, אך התקנת PWA, מיקום והעתקה דורשים בדרך כלל HTTPS (או localhost במחשב).

## מה עובד

- ארנק אישי ריק בתחילת הדרך, עם מצב הדגמה נפרד ונתונים פיקטיביים המסומנים במפורש.
- הוספה, עריכה, מחיקה, חיפוש לפי שובר/חנות, קטגוריה, מצב ומיון.
- חילוץ שמות מנפיקים מוכרים, סכום, קוד, תוקף ורשימת חנויות מפורשת מטקסט. חובה לאשר את הפרטים.
- קטלוג ציבורי ל־Swish Premium/Rainbow ולמסלולי DREAM CARD מוגדרים, עם אישור סוג לפני ייבוא עסקים, מקור ותאריך בדיקה. זיהוי פלטפורמת מולטיפאס נשמר בנפרד מזיהוי המוצר. [פירוט הבדיקה ומקורות](RESEARCH.md).
- OCR מקומי של תמונות JPG/PNG/WebP בעברית ואנגלית. טעינת מנוע ושפות דורשת אינטרנט. התמונה אינה נשלחת לשרת OCR; קבצי המנוע והשפות נטענים מספקי הספרייה.
- שמירת קישור וזיהוי מנפיק מכתובת. **אין כרגע קריאת תוכן אוטומטית מאתר השובר.** אפשר להדביק את הטקסט מהאתר או לצרף צילום.
- יתרה, תוקף, תנאים, תמונה מקורית, קוד מימוש, רישום מימוש חלקי והיסטוריה. היתרה מתעדכנת ידנית; אין חיבור למנפיק.
- חנויות מתוך השוברים הפעילים, סניפים שמוזנים ידנית, מפה, סינון עיר/חנות/קטגוריה, מרחק בקו אווירי וניווט ל־Google Maps.
- גיבוי ושחזור JSON, עם אימות הקובץ ואישור לפני החלפת נתונים.
- manifest ו־service worker להתקנה ופתיחת הארנק שכבר נטען גם ללא חיבור. מפה וטעינה ראשונית של OCR דורשות רשת.

## מגבלות מכוונות

יש קטלוגים שנקראו מאתרים ציבוריים של המנפיקים, אך אין מאגר סניפים מלא או אימות מול הכרטיס האישי. הקטלוגים אינם מתעדכנים אוטומטית. אין עדיין סנכרון בין מכשירים, חשבונות, התראות רקע או שירות שרת. אותו מותג עשוי להנפיק שוברים בעלי תנאים שונים, ולכן נדרש אישור סוג המוצר. המפה מציגה רק סניפים שהוזנו, ולא את כל הסניפים בישראל. נתוני הדגמה אינם טענה על זכאות בחנויות אמיתיות. זיהוי טקסט מבוסס כללים ולא מבין את כל נוסחי השוברים.

הנתונים נשמרים בדפדפן ואינם מוצפנים באפליקציה; ניקוי אחסון הדפדפן מוחק אותם. הגיבוי מכיל קודים ותמונות ויש לשמור אותו באופן פרטי. מפות מקבלות בקשות לאריחים; בקשות אלה חושפות לספק את כתובת ה־IP והאזור המוצג, אך לא את קודי השוברים. נתוני המיקום משמשים מקומית לחישוב מרחק. יש לכבד את מדיניות שרת האריחים של OpenStreetMap לפני פריסה רחבה.

## המשך מומלץ

1. לאסוף דוגמאות אמיתיות של סוגי שוברים רצויים (עם קודי מימוש מוסתרים), ולהגדיר מתאמי זיהוי לכל מנפיק.
2. שרת חילוץ לקישורים, עם הגנת SSRF, הגבלת גודל וזמן, בדיקת הפניות ורשימת דומיינים; שוברים עם התחברות דורשים טיפול ייעודי. מודל חילוץ מובנה צריך להשאיר שדות לא ידועים ריקים ולשמור מקור לכל עובדה.
3. קטלוג רשתות וסניפים ממקורות מורשים, כולל מקור, תאריך אימות, חריגי סניפים ותנאים לפי מוצר. אפשר לחבר Google Maps JavaScript/Places עם מפתח מוגבל ובקרת עלויות.
4. חשבון משתמש וסנכרון מאובטח, ואז ארנק משפחתי עם הרשאות ומניעת מימוש מקביל.
5. התראות לפני תפוגה (30/7/1 ימים), שיתוף אל האפליקציה מתפריט Android, מועדפים ורשימת קניות שמראה איזה שובר מתאים לכל חנות.
6. ״מה כדאי לממש עכשיו״ לפי תוקף, מרחק, יתרה והעדפות; זיהוי כפילויות חזק יותר; היסטוריית יתרות; ייצוא ליומן ומצב קופה עם תמונה/ברקוד מקורי.

### בדיקת שני השוברים האישיים

שרת הפיתוח המקומי מייבא פעם אחת את `.local/wallet-import.json` לאחסון הדפדפן, בלי להחליף שוברים קיימים. הקובץ פרטי ומוחרג מ־Git ומגישה סטטית; נקודת הייבוא זמינה רק במצב פיתוח ומכתובת loopback. הוא אינו נכלל בבניית הייצור. יש לפתוח את `http://127.0.0.1:5173` במחשב זה. להעברה לטלפון אפשר לייצא גיבוי דרך האפליקציה ולייבא בהתקנה אחרת; אין סנכרון אוטומטי.

יתרה לא ידועה נשמרת כ־null: השובר משתתף בחיפוש עסקים, אינו נחשב ממומש, אינו נכלל בסך היתרות הידועות, ולא ניתן לרשום מימוש עד לעדכון יתרה.

מפת הבדיקה כוללת 75 סניפי ללין שנשלפו מדף הסניפים הרשמי (`https://www.laline.co.il/pages/branches`). הכתובות וקואורדינטות ll נלקחו מקישורי Waze באותו דף; סניפים בלי קואורדינטות ובעלי טקסט סגירה זמנית/עודפים הושמטו. המקור ותאריך הבדיקה שמורים בכל רשומה ב־`src/data/branches.json`. זו תמונת מצב חלקית, ואינה אימות פרטני של זכאות בסניף. הקישור בין LALINE לללין מאפשר להציג את שני השוברים באותו סניף.

### מאגר משותף ומפה לפי שובר

`src/data/branches.json` הוא מאגר סניפים משותף וקבוע, הנכלל באפליקציה ובמטמון האפליקציה לשימוש חוזר. `src/branches.mjs` מחבר בין שמות רשת מוכרים בעברית ובאנגלית ומונע סמנים כפולים באותה רשת ובאותן קואורדינטות. המיקומים אינם נאספים מחדש עבור כל שובר. זכאות נקבעת בכל פעם מרשימת העסקים של השובר; רשומת סניף לבדה אינה הוכחה שהוא מכבד כל סוג שובר של הרשת. סניפים ידניים נשמרים בארנק ובגיבוי שלו ומשמשים גם שוברים חדשים.

בפרטי שובר, ״הצג חנויות על המפה״ פותח מפה מסוננת לשובר הנבחר ומאפס מסננים קודמים. אפשר להחליף שובר במפה או לחזור לכל השוברים הפעילים. גם שובר שיתרתו לא ידועה משתתף; בשובר שמומש או פג תוקף מופיעה הודעה שהמפה לעיון בלבד.

השלמת מיקומים ראשונה (20.09.2026): נוספו 21 סניפי FOX מתוך דף הסניפים הרשמי. כעת יש 96 רשומות מקור ו־95 מיקומים לאחר איחוד כפילות בללין. עוד 59 רשומות FOX הושארו לבדיקה או חסרות קישור ניווט. קובץ `src/data/branch-sources.json` מתעד את הכיסוי החלקי וההשמטות; `scripts/update-branches-fox.mjs` מעדכן את הקבוצה שנבדקה ושומר על המאגר הקודם אם המקור השתנה באופן בלתי צפוי. כתובות FOX הן שמות מתחמים כפי שסופקו באתר, ולא כתובות רחוב שהוסקו.

### מעקב השלמת רשתות

בהגדרות נוסף מסך ״מעקב מיפוי חנויות״, לפי סוג שובר. הוא מציג מספר רשתות שהושלמו, עם כיסוי חלקי, שנבדקו אך דורשות השלמה, ושטרם נבדקו. לכל רשת מוצגים מיקומים ייחודיים, מקור ותאריך. מספר סניפים שנותרו מחושב רק כאשר מספר הרשומות במקור ידוע. רשימה שהתקבלה ממקור ציבורי אינה הוכחת שלמות: השלמה דורשת סימון מפורש ותאימות לספירת המיקומים. תוכנית הטלפון והפרסום המוכן מפורטות ב־MOBILE.md. סבב האיסוף הנוכחי בלבד אושר; לא נקבעה אוטומציה מחזורית.

הסנכרון זמין כעת; תיאורי הגרסה המקומית בלבד למעלה מתייחסים למצב לפני חיבור ארנק לענן. בהגדרות במכשיר שבו נמצאים השוברים בוחרים ״יצירת ארנק מסונכרן מהשוברים שלי״. שומרים את המפתח במקום בטוח. במכשיר השני מזינים אותו ובוחרים ״חיבור לארנק קיים״; החיבור מחליף את הארנק המקומי לאחר אישור. אין שחזור מפתח דרך מייל. גיבוי JSON מכיל את השוברים אך אינו כולל מפתח ענן.

AES-GCM מצפין את התוכן בדפדפן; בשרת נשמרים טקסט מוצפן, גיבוב אסימון ומספר גרסה. כתיבה דורשת רשת והשוואת גרסה אטומית. עדכונים נבדקים בפתיחה, בחזרה לחלון וכל30 שניות כשהאפליקציה גלויה ואין עריכה פתוחה. בהתנגשות סוגרים עריכה, מרעננים מהענן ומבצעים את השינוי מחדש; אין מיזוג אוטומטי. ניתוק משאיר עותק מקומי ואינו מוחק את הענן.
